# ROLEy 机械资料索引

ROLEy 的机械结构、电子硬件和软件均由作者完成。本页把原生 CAD、实物照片与机电连线资料放在一起，便于从整机外观继续查看内部设计。

## 原生 CAD

机械设计保存在 Onshape 文档 **「乐易服务机器人」** 中，原目录为 `sustech/大四大项目`。

| 入口 | 内容 |
| --- | --- |
| [整机总装：乐易机器人](https://cad.onshape.com/documents/4b50ff97ae325c76e82c3ad7/w/b60b42699d5772013056fe9f/e/4009ac390b845918af88e4d9) | 查看整机各部分的装配关系 |
| [底盘装配](https://cad.onshape.com/documents/4b50ff97ae325c76e82c3ad7/w/b60b42699d5772013056fe9f/e/cc0b1561104cf17267746cdf) | 查看底盘及相关机构 |

文档中可见的设计内容包括：

- 躯体与底盘。
- 全向轮组、气轮组与电池装配体。
- 灰度传感器连接件、开发板后壳。
- 各零件、装配体与工程图。

原生模型仍在 Onshape，本仓库未包含完整 CAD 导出包。现有链接共享允许查看和导出，链接沿用文档原有访问范围。
